CineReview - Movie Rating Platform
A modern movie rating and review platform built with HTML, CSS, and JavaScript featuring glass morphism design and interactive rating system.
Features

Add movies with title, genre, year, poster URL, rating, and review
Interactive 5-star rating system
Filter movies by genre
Sort by title, rating, year, or date added
Real-time statistics (total movies, average rating, top genre)
Responsive design for all devices
Local storage for data persistence
Delete movies functionality

Technologies Used :

HTML5
CSS3 (Glass morphism effects, animations, responsive design)
JavaScript (ES6+ class-based architecture)
Font Awesome icons

How to Run :

Download all files (index.html, styles.css, script.js)
Open index.html in any modern web browser
Start adding and rating movies

File Structure :

├── index.html    # Main HTML structure
├── styles.css    # All styling and animations
└── script.js     # JavaScript functionality
